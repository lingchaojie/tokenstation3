## 语义合并结果

本轮逐域审阅冲突与自动合并区，而不是整文件选择 ours/theirs。最终保留本地 KIRO、WebChat、ClickHouse capture、LINX2 品牌、支付/奖励、统一 Key 与部署约定，并纳入固定上游范围的安全修复、调度优化、计费观察字段、认证基础、前端和部署更新。

主要决策如下：

- 迁移按本地序列重排并保留已占用编号；Product Composite 整体排除，统一 Key 继续承担跨平台入口。
- Passkey、Session Binding、Step-up 仅保留默认关闭的后端基础；Tencent/Aliyun captcha、Prompt Audit 和 Panel Rate Limit 运行时接入排除。WebChat prompt 不写入通用 audit body。
- KIRO direct/relay/mixed、profile ARN、machine ID、sticky/cooldown、模型级 invalid-model 限流、credits 和独立调度桶保持；KIRO 不加入 profit-control、调度阈值或 upstream billing probe。
- Gateway/OpenAI/Anthropic/Gemini/Grok/KIRO 的首语义输出、重试边界、partial billing、最终 provider-native request/response capture、错误截断和 exact-once side effects 按真实 attempt 对齐。
- Grok Voice/TTS/STT/Realtime、custom voices 和独立 web-search surface 排除；按模型视频价格保留兼容回退；cross-client mapping 与 Free gate 默认关闭。
- usage log 取本地 `kiro_credits` 与上游 response observation、image input ledger、session 字段的并集；response model 仅观察，不重定价、不触发 mismatch retry；image input 沿用文本输入单价；自动 multiplier 写回排除。
- 用户 self-service refund、`require_force`/clamp 新口径和 Alipay mobile deep-link 排除；保留管理员部分余额退款口径，并合入 pending refund 原子化、行锁、commit 后 cache invalidation、Stripe 幂等和 EasyPay UTF-8 修复。
- 前端保留 KIRO/WebChat/getting-started/public-minimal、LINX2、127.0.0.1/Caddy/镜像约定；纳入 channel-monitor-v2、batch image 与部署 hardening；恢复 `nanoid` 安全 pin。
- 推送前 dev 漂移的 capture runtime-admin 功能与本轮 provider-native capture 合并：master 默认关闭；平台策略覆盖 Anthropic、KIRO、OpenAI、Gemini、Antigravity、Grok；KIRO 内层 AWS 原始响应不会被外层转换 SSE 覆盖。
