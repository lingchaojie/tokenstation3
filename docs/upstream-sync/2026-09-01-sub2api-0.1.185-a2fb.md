## 计费与终态语义

“幂等”只用于数据库计费提交：同一 durable identity/fingerprint 重试不会重复扣款或重复写
usage；复用 identity 但 fingerprint 不同会被拒绝。本地 handler 的 capture-first/usage
callback pair 由该请求内的一个 `sync.Once` 保护，所以每个进程内 callback 是 at-most-once。
usage logging 与 capture delivery 均是 best effort。这里不承诺跨进程、跨网络或所有副作用的
global exactly-once delivery。
