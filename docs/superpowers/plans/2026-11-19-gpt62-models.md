# GPT-6.2 Models Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** List and route GPT-6.2 Sol/Astra with independent standard prices and fixed Fast 2x / Ultra Fast 6x billing.

**Architecture:** Extend existing model recognizers, pricing cards and Codex descriptors without changing the funding pipeline. Reuse the public catalog and account preset UI. Keep the previous upstream pin as a reference rather than merging unrelated history.

**Tech Stack:** Go, Vue/TypeScript, Vitest, existing JSON pricing and Codex metadata.

**Spec:** `docs/superpowers/specs/2026-11-19-gpt62-models-design.md`.

## Global Constraints

- Fast 2x; Ultra Fast 6x at every request date; no 3x promotion.
- No unrelated upstream sync, dependency upgrade, migration or change to existing model prices.
- Preserve local price priority, explicit zero, funding order, quotas, capture and routing.
- Production writes and billable verification wait for concrete release confirmation.

## Review Focus

- Unknown lookalikes must not acquire known-model prices or credentials.
- Aliases and mapped upstream IDs retain the correct model identity and subscription qualification.
- Channel/group prices and zero-valued buckets keep their current precedence.
- Native/bridged requests preserve required reasoning parameters and reject unsupported disabled reasoning.
- Offline API-key manifests must not advertise ChatGPT-only transport or ungranted OAuth capabilities.
